# CourseAI

CourseAI היא אפליקציית Full-Stack למציאת קורסים ומסלולי לימוד, שמירת קורסים אישית וקבלת הכוונה באמצעות סוכן AI.

הפרויקט נבנה באמצעות `Next.js App Router` ובשפת `JavaScript`.

## תכונות עיקריות

- הרשמה והתחברות למשתמשים
- התחברות באמצעות Google
- ניהול התחברות באמצעות `JWT` בעוגיית `HTTP-only`
- שמירת קורסים אישית לכל משתמש
- חיפוש קורסים ומסלולי לימוד
- הוספת קורסים למועדפים
- סוכן AI להתאמת מסלול לימודים
- זיכרון היסטוריית השיחה
- שמירת שיחות במסד הנתונים
- התאמת המלצות לפי הקורסים שהמשתמש שמר
- ממשק רספונסיבי למחשב ולמובייל

## טכנולוגיות

- `Next.js`
- `React`
- `JavaScript`
- `MongoDB` + `Mongoose`
- `OpenAI Agents SDK`
- `Apify`
- `bcrypt`
- `JWT`
- `shadcn/ui`
- `Tailwind CSS`

## הרצת הפרויקט

### 1. התקנת החבילות

```bash
npm install
```

### 2. משתני סביבה

העתיקו את `.env.example` ל-`.env.local` והשלימו את הערכים. לחיפוש קורסים נדרש `APIFY_TOKEN`. ברירת המחדל היא `apify~google-search-scraper`.

### 3. הפעלה

```bash
npm run dev
```

## חיפוש קורסים

חיפוש הקורסים מתבצע באמצעות Apify Google Search Results Scraper. האפליקציה משתמשת רק בתוצאות החיפוש המובנות (`organicResults`) ומסננת דפי בחינות, מסמכי PDF ותוצאות שאינן נראות כדפי קורס. סוכן ה-AI אינו משמש לעיבוד תוצאות Apify; הוא מיועד לצ'אט והכוונה למשתמש בלבד.
