# CourseAI

CourseAI היא אפליקציית Full-Stack למציאת קורסים ומסלולי לימוד, שמירת קורסים אישית וקבלת הכוונה באמצעות סוכן AI.

הפרויקט נבנה באמצעות `Next.js App Router` ובשפת `JavaScript`.

## תכונות עיקריות

- הרשמה והתחברות למשתמשים
- התחברות באמצעות Google
- ניהול התחברות באמצעות `JWT` בעוגיית `HTTP-only`
- שמירת קורסים אישית לכל משתמש
- חיפוש קורסים ומסלולי לימוד
- הוספת קורסים למועדפים
- סוכן AI להתאמת מסלול לימודים
- זיכרון היסטוריית השיחה
- שמירת שיחות במסד הנתונים
- התאמת המלצות לפי הקורסים שהמשתמש שמר
- ממשק רספונסיבי למחשב ולמובייל

## טכנולוגיות

- `Next.js`
- `React`
- `JavaScript`
- `MongoDB` + `Mongoose`
- `OpenAI Agents SDK`
- `Apify`
- `bcrypt`
- `JWT`
- `shadcn/ui`
- `Tailwind CSS`
